# Short Video Maker

Telegram-бот, который анализирует видео или публичную ссылку, ищет потенциально интересные фрагменты, вырезает короткие клипы и присылает каждому оценку интересности.

## Что умеет
- Принимать видеофайлы и публичные ссылки на видео.
- Анализировать выбранные кадры через Groq Vision.
- Распознавать речь и получать таймкоды через Groq Whisper.
- Выбирать до 1, 3, 5 или 10 фрагментов с оценкой 1–100 через Groq Text.
- Вырезать клипы через FFmpeg.
- Включать и выключать встроенные субтитры в настройках Telegram.
- Сжимать итоговые ролики для отправки в Telegram.

## Развёртывание на Render

В репозитории есть Dockerfile и render.yaml.

1. Создай Telegram-бота и скопируй токен.
2. Создай API-ключ Groq.
3. В Render выбери создание Blueprint из этого репозитория (или создай Docker Web Service).
4. Добавь переменные окружения:
   - `BOT_TOKEN` — токен Telegram-бота.
   - `GROQ_API_KEY` — ключ Groq.
   - `WEBHOOK_URL` — публичный адрес Render-сервиса, например `https://short-video-maker.onrender.com`, без слеша в конце.
   - `WEBHOOK_SECRET` создаётся Blueprint автоматически.
5. Запусти Deploy и дождись успешного завершения.
6. Открой бота в Telegram и отправь `/start`.

Render должен использовать Dockerfile из корня репозитория. Вебхук Telegram настраивается автоматически при старте приложения.

## Модели Groq

Настройки по умолчанию:
- `GROQ_TEXT_MODEL=openai/gpt-oss-20b`
- `GROQ_VISION_MODEL=qwen/qwen3.8-27b`
- `GROQ_STT_MODEL=whisper-large-v3-turbo`

Эти модели есть в актуальном каталоге Groq на момент добавления проекта. Бесплатный тариф имеет ограничения по запросам, токенам и длительности аудио. При превышении лимита API вернёт ошибку ограничения (например, 429); бот не может обойти эти лимиты. Доступность моделей и квоты могут изменяться — проверь раздел Limits в своей Groq Console. Не переходи на Developer/платный тариф, если хочешь оставаться на бесплатном использовании.

## Ограничения текущей версии

- Видео, загруженное непосредственно в Telegram, ограничено лимитом скачивания Telegram Bot API (до 20 МБ для обычного облачного Bot API).
- Для публичных ссылок действует лимит скачивания по умолчанию 250 МБ (`MAX_DOWNLOAD_MB`).
- Максимальная длительность исходного видео по умолчанию — 90 минут (`MAX_VIDEO_MINUTES`).
- Ссылки на приватные видео, контент за платным доступом или видео, для которых нужна авторизация, могут не работать. Бот не обходит DRM и ограничения доступа.
- Render Free имеет ограниченные CPU/RAM, может засыпать и использует временный диск. Длинные видео могут обрабатываться долго или не поместиться в ресурсы бесплатного сервиса.
- Настройки количества клипов и субтитров хранятся в памяти и сбрасываются после перезапуска Render.
- Субтитры формируются по распознанной речи. Если в видео нет речи или Whisper не смог её распознать, субтитров не будет.
- Оценка 1–100 — субъективная оценка модели, а не прогноз просмотров или заработка.

Используй только видео и ссылки, которые ты имеешь право обрабатывать и публиковать. Для чужих стримов заранее получай разрешение автора и учитывай правила платформ, на которых будешь публиковать нарезки.

## Локальный запуск

Нужны Python 3.11+ и FFmpeg.

```bash
pip install -r requirements.txt
export BOT_TOKEN="..."
export GROQ_API_KEY="..."
export WEBHOOK_URL="https://публичный-домен"
python bot.py
```

Для локальной разработки нужен доступный из интернета HTTPS-домен, потому что Telegram доставляет обновления через webhook.
